How to use this in a club session

  1. Predict: before touching a slider, write down what you expect.
  2. Play: change one variable at a time and watch the readouts.
  3. Explain: describe the pattern in words before opening the optional physics panel.
  4. Challenge: try the purple challenge box, then mark the experiment explored.
